# SCT_DS_2 - Data Cleaning and Preparation

##  Project Overview

This project focuses on cleaning and preparing the Global Superstore dataset using Python and the Pandas library. Data cleaning is an essential step in the data analysis process as it improves data quality, consistency, and reliability.

The project involves handling missing values, removing duplicate records, converting date columns into appropriate data types, and exporting a cleaned dataset for further analysis.

---

##  Objective

The objective of this task is to:

* Load a dataset using Pandas
* Identify and handle missing values
* Remove duplicate records
* Convert date columns to datetime format
* Export the cleaned dataset to a new CSV file

---

##  Dataset

* Dataset Name: Global Superstore Dataset
* File Format: CSV
* Records: 51,290+
* Features: 27 columns

---

##  Tools and Technologies

* Python
* Pandas
* Visual Studio Code
* CSV Files

---

##  Data Cleaning Steps

1. Loaded the dataset using Pandas.
2. Inspected dataset structure and column information.
3. Checked for missing values.
4. Identified and removed duplicate records.
5. Converted `Order.Date` and `Ship.Date` columns to datetime format.
6. Removed incomplete records containing missing values.
7. Exported the cleaned dataset as `superstore_cleaned.csv`.
